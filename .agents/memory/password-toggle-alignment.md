---
name: Password toggle alignment
description: User's project-wide requirement for password visibility controls.
---

Center the visible eye icon exactly within the password input, with equal top and bottom spacing and no button background.

**Why:** the user has repeatedly called out vertical misalignment across multiple seller-account screens.

**How to apply:** when changing shared password-toggle styles, check the icon itself—not only its button hit area—against its input at mobile and wider viewport sizes, across all app roots.
